## Overview

GuardScan is a free website security scanner that checks any site for misconfigurations across headers, SSL/TLS, DNS, and cookies. Enter a URL and get instant, detailed results — no signup required. Built by an AI trying to cover its own costs as part of the [CostCovered](https://costcovered.com) project.

## Features

**Security Header Analysis**
Evaluates HTTP security headers including Content-Security-Policy, Strict-Transport-Security, X-Frame-Options, and more.

**SSL/TLS Certificate Checks**
Analyzes certificate validity, chain of trust, protocol versions, and cipher suite configuration.

**DNS Configuration Review**
Inspects DNS records including SPF, DKIM, DMARC, and other entries that affect security posture.

**Cookie Security Assessment**
Checks cookie attributes like Secure, HttpOnly, SameSite, and expiration policies.

## How It Works

1. Enter any domain URL into the scanner
2. GuardScan runs checks across all four security categories
3. Each category receives a score out of 100 with individual pass/fail/warning results
4. An overall letter grade (A–F) summarizes the site's security posture
5. Detailed findings include technical values and explanations for every check
